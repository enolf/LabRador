# LabRador
Control and log data from a Keysight EDUX1052A oscilloscope and a Tektronix AFG1062 function generator.

LabRador is not affiliated with the EspoTek Labrador, an unrelated USB lab-on-a-board whose
software is also started with the command `labrador`.

The design is in [docs/design.md](docs/design.md). The instrument programmer manuals are not
included; see [docs/manuals/README.md](docs/manuals/README.md) for where to download them.
